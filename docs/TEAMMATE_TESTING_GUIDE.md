FlowMind: проста інструкція для тестування на Windows

Цей файл допоможе запустити FlowMind на Windows, протестувати веб-дашборд і окремо попрацювати через Project Manager.
Тут не треба глибоко розбиратися в коді.
Головна задача: встановити потрібні компоненти, запустити проєкт, поклацати базові сценарії і написати короткий звіт.


1. Що потрібно

Потрібно мати Windows 10 або Windows 11.
Всі команди нижче краще запускати у PowerShell.

Щоб відкрити PowerShell:
натисни Win
напиши PowerShell
відкрий Windows PowerShell


2. Встановлення Python 3.12.13

Скопіюй і виконай команду:

winget install --id Python.Python.3.12 --version 3.12.13 --source winget

Після встановлення закрий PowerShell і відкрий його заново.

Перевір Python:

python --version

Очікувано має бути щось схоже:

Python 3.12.13

Якщо команда python не працює, спробуй:

py --version


3. Встановлення Git

Скопіюй і виконай команду:

winget install --id Git.Git --source winget

Після встановлення закрий PowerShell і відкрий його заново.

Перевір Git:

git --version

Якщо показало версію Git, все добре.


4. Клонування конкретної гілки репозиторію

Перейди у папку, де хочеш зберегти проєкт.
Наприклад, у Documents:

cd $HOME\Documents

Склонуй потрібну гілку:

git clone -b feature/pre-mvp --single-branch <ПОСИЛАННЯ_НА_РЕПОЗИТОРІЙ>

Перейди в папку проєкту:

cd FlowMind

Заміни <ПОСИЛАННЯ_НА_РЕПОЗИТОРІЙ> на реальне посилання на репозиторій.


5. Створення віртуального середовища

Виконай:

python -m venv .venv

Активуй середовище:

.venv\Scripts\activate

Якщо все добре, у PowerShell зліва з'явиться:

(.venv)

Якщо PowerShell не дозволяє активувати середовище, виконай:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Потім ще раз:

.venv\Scripts\activate


6. Встановлення залежностей проєкту

Переконайся, що ти в папці FlowMind і що середовище активоване.

Виконай:

python -m pip install --upgrade pip

Потім:

pip install -r requirements.txt

Це може зайняти кілька хвилин.
Якщо буде помилка, скопіюй останні 20-30 рядків помилки і скинь у чат команди.


7. Швидка перевірка, що backend працює

Виконай:

python -m unittest tests.test_web_dashboard_api

Очікуваний результат:

OK

Якщо бачиш OK, можна запускати веб-дашборд або Project Manager.


8. Запуск веб-дашборду напряму

Виконай:

uvicorn api.web_dashboard:app --host 127.0.0.1 --port 8010

Після запуску має бути щось схоже:

Uvicorn running on http://127.0.0.1:8010

Тепер відкрий у браузері:

http://127.0.0.1:8010

Додаткові сторінки:

http://127.0.0.1:8010/archive

http://127.0.0.1:8010/averages

Важливо:
поки тестуєш сайт, не закривай PowerShell з uvicorn.


9. Як запустити Project Manager

Project Manager це віконна програма для запуску різних частин системи кнопками.
Через нього зручніше тестувати симуляцію, сценарії, dashboard, SUMO і системні перевірки.

Переконайся, що ти в папці FlowMind і що середовище активоване.

Запуск:

python project_manager.py

Якщо відкриється вікно FlowMind Project Manager, все добре.

Якщо вікно не відкрилось:
подивись помилку в PowerShell
скопіюй останні 20-30 рядків
скинь у чат команди


10. Вкладка Експерименти у Project Manager

У цій вкладці запускаються основні симуляції.

Карта або сценарій
Тут вибирається папка сценарію з simulation.
Зазвичай можна залишити стандартний сценарій.

Кнопка Оновити
Оновлює список сценаріїв.
Корисно, якщо з'явилась нова папка у simulation.

Кнопка Обрати папку
Дозволяє вручну вибрати папку сценарію.
Новачку краще не чіпати, якщо стандартний сценарій уже вибраний.

Режим
Вибір алгоритму керування світлофорами.

Fixed
Базовий режим зі стандартними світлофорами.
Використовується як baseline.

Local Adaptive
Локальна адаптація за станом перехресть.

FlowMind
Основний режим системи.
Він використовує дані з датчиків біля перехресть і може працювати з ML-прогнозом черг.

Тривалість, с
Скільки секунд триває симуляція.
Для першого тесту краще 120 або 300.

Seed
Число для повторюваності симуляції.
Якщо змінити seed, сценарій руху буде трохи інший.

Розмір зони
Скільки перехресть або зона керування береться в симуляцію.
Для простого тесту можна не міняти.

GUI delay, мс
Затримка для SUMO GUI.
Якщо SUMO GUI відкритий, більше значення робить симуляцію повільнішою і зручнішою для перегляду.

Порт dashboard
Порт для Streamlit dashboard, який запускає менеджер.
Зазвичай 8501.

Дальність датчиків, м
Радіус, у якому камера або датчик біля перехрестя бачить авто.
Для тесту можна пробувати 80, 120, 180.

Відкрити SUMO GUI
Якщо увімкнено, відкривається вікно SUMO з візуальною симуляцією.
Це красиво для демонстрації, але може бути важче для слабкого комп'ютера.

Live dashboard
Якщо увімкнено, менеджер відкриває dashboard з live-метриками.

WebSocket порт
Порт для live-оновлень між симуляцією і dashboard.
Зазвичай можна не змінювати.

Створити швидку
Якщо увімкнено, в симуляції буде emergency vehicle.
Це потрібно для demo зі швидкою і повної системи.

Виїзд швидкої, с
На якій секунді симуляції з'явиться швидка.
Для тесту можна ставити 40, 120 або 180.

ML-прогноз черг
Вмикає прогнозування черг через моделі з папки models.
Для повної системи краще увімкнути.

Моделі прогнозу
Тут можна вибрати набір моделей.
Найважливіший варіант:
30/60/90 ensemble
Це ансамбль моделей для прогнозу черг на 30, 60 і 90 секунд.

Файли .joblib
Шляхи до моделей прогнозу.
Якщо вибрано 30/60/90 ensemble, вони підставляються автоматично.

SUMO config
Файл конфігурації SUMO.
Новачку краще не міняти.

Конфігурація зони
JSON з контрольованими перехрестями.
Новачку краще не міняти.

Швидка або emergency
JSON з налаштуваннями швидкої.
Новачку краще не міняти.

Результати
Папка, куди записуються результати симуляції.
Зазвичай це results або results з назвою сценарію.

перевір, чи з'явились нові результати

Demo зі швидкою
Запускає сценарій з emergency vehicle.

Що тестити:

перевір, чи процес стартував

Demo прогнозу
Запускає демо з ML-прогнозом черг.
Потрібно, щоб показати роботу моделей прогнозування.

Що тестити:

перевір у журналі, чи процес стартував

Відкрити dashboard
Відкриває Streamlit dashboard, який уже був у проєкті.
Це не FastAPI dashboard на 8010.
Зазвичай менеджер відкриває його на порті 8501.

Закрити dashboard
Закриває dashboard, який був відкритий менеджером.

Зупинити процес
Кнопка внизу вікна.
Зупиняє поточний запущений процес.
Корисно, якщо симуляція зависла або ти запустив занадто довгий сценарій.


12. Вкладка Сценарій та система у Project Manager

Ця вкладка потрібна для підготовки сценарію і перевірки середовища.

Тривалість трафіку, с
Скільки секунд трафіку треба згенерувати.
Для тесту можна 600 або 1200.

Авто/год
Інтенсивність трафіку.
Для легкого тесту можна 1200.
Для важчого тесту можна 3600.

Кількість маршрутів
Скільки маршрутів генерувати.
Для простого тесту можна 4 або 8.

Згенерувати трафік
Створює traffic routes для поточного сценарію.
Це корисно, якщо треба підготувати новий потік машин.

Що тестити:
постав Тривалість трафіку 600
постав Авто/год 1200
постав Кількість маршрутів 4
натисни Згенерувати трафік
подивись у журналі, чи процес завершився без помилки

Відкрити сценарій у SUMO
Відкриває поточний сценарій у SUMO GUI.
Це просто візуальна перевірка карти.

Інфо по карті
Показує інформацію про вибрану карту і файли сценарію.
Корисно, щоб зрозуміти, чи всі потрібні файли знайдені.

Перевірити середовище
Перевіряє Python, SUMO, SUMO GUI, сценарій і потрібні файли.
Це перша кнопка, яку варто натиснути, якщо щось не працює.

Запустити тести
Запускає тести проєкту.
Це може зайняти трохи часу.
Якщо тести проходять, середовище більш-менш нормальне.

Встановити або оновити залежності
Запускає встановлення залежностей з requirements.txt.
Це зручно, якщо користувач не хоче робити pip install вручну.

14. Що треба перевірити на FastAPI dashboard

Якщо запускаєш FastAPI dashboard напряму через uvicorn, перевір:

http://127.0.0.1:8010

Тут має бути live dashboard.

http://127.0.0.1:8010/archive

Тут має бути архів симуляцій.

15. Що не треба тестувати
