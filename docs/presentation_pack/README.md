# FlowMind Presentation Pack

Ця папка містить стислу вижимку по FlowMind для підготовки сценарію захисту, розмови з менторами та пояснення демо журі.

Файли:

- `01_project_overview.md` - що робить проєкт, яку проблему вирішує, у чому ідея.
- `02_presentation_script.md` - готовий каркас сценарію презентації.
- `03_metrics_and_numbers.md` - цифри, які зараз видає система, з поясненням як їх правильно показувати.
- `04_technical_architecture.md` - технічна архітектура простими словами.
- `05_mentor_questions.md` - відповіді на типові питання менторів/журі.

Головна позиція для презентації:

> FlowMind - це MVP системи зонального керування світлофорами. Вона не просто реагує на одну чергу на одному перехресті, а дивиться на групу пов'язаних перехресть, прогнозує черги на 30/60/90 секунд і змінює світлофори так, щоб розвантажувати всю контрольовану зону.
